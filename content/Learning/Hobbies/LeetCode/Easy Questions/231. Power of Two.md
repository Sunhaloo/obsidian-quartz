```python
def isPowerOfTwo(self, n: int) -> bool:
	return n > 0 and n == n & (-n)
```

## Explanation Of Solution

- Check if `n` is greater than 0 as `math.log2(0)` is going to cause some issues
- Check if the value of `n` is the same as:
	- `-n` is the **two's complement** of `n`
	- `n & (-n)` is going to apply the `&` / `AND`'s truth table
- If the number is a power of 2; therefore it will return `True`

### Example:

```console
n = 8

8: 1000
-8: 1000 ( applying two's complement --> reverse and then add '1' )

# therefore apply the AND's truth table
1000
1000 &
----
1000
----
```

> Hence we see that `n == n & (-n)` is `True` and this is going to work with numbers whereby `n` is actually a **power of 2**!
