# My Answer

> [!INFO] Resource(s)
> - [[Python - Merge Sort]]

> [!NOTE]
> In this case, I just applied the '*Neural Nine*' version of **merge sort** whereby the *base case* is `if left > = right: return` compared to '*NeetCode*' `if left == right: return nums`
>
> > Which is basically the **same** thing!
>

```python
def sortArray(self, nums: List[int]) -> List[int]:
	# conquer / combine `merge` function
	def merge(nums, left_index, right_index, mid_index):
		# create copies of the numbers list
		left_part = nums[left_index : mid_index + 1]
		right_part = nums[mid_index + 1 : right_index + 1]

		# create the pointer for our main array and array parts
		main_ptr = left_index
		left_ptr = right_ptr = 0

		# actually start the merging process ( with sorting in order )
		while left_ptr < len(left_part) and right_ptr < len(right_part):
			# if the left part of array contains the lower value
			if left_part[left_ptr] < right_part[right_ptr]:
				# swap the value with the main list
				nums[main_ptr] = left_part[left_ptr]

				# increment the pointer for the left part of list
				left_ptr += 1

			# if the right part of array contains the lower value
			else:
				# swap the value with the main list
				nums[main_ptr] = right_part[right_ptr]

				# increment the pointer for the right part of list
				right_ptr += 1

			# finally whatever the case / condition above may be
			# simply increment the main pointer for the main list
			main_ptr += 1

		# if the length of the left part is greater than right part
		while left_ptr < len(left_part):
			# as the data is already sorted ==> just "swap" with main list
			nums[main_ptr] = left_part[left_ptr]

			# increment both pointers
			left_ptr += 1
			main_ptr += 1

		# if the length of the right part is greater than left part
		while right_ptr < len(right_part):
			# as the data is already sorted ==> just "swap" with main list
			nums[main_ptr] = right_part[right_ptr]

			# increment both pointers
			right_ptr += 1
			main_ptr += 1


	# main `merge_sort` function that will return the sorted list
	def merge_sort(nums, left, right):
		# check if the base case has been reached ==> only one data left
		if left > = right:
			# simply exit the current `merge_sort` function
			return nums

		# if list can be splitted again
		mid = (left + right) // 2

		# call the function on the smaller left part
		merge_sort(nums, left, mid)
		# call the function on the smaller right part
		merge_sort(nums, mid + 1, right)

		# finally combine all the invidiual values in sorted manner
		merge(nums, left, right, mid)

		# thus return the sorted ( in-place ) list
		return nums

	# hence, call the function to actually sort the list required
	return merge_sort(nums, 0, len(nums) - 1)
```
